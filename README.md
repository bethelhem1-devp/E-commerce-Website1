Kebir Men's Wear

A simple e-commerce website 

Built with plain HTML, CSS, and JavaScript. 

Features
Product categories: Suits, Casual Wear, Shoes
Shopping cart (saved in your browser)
Checkout via WhatsApp or Telegram — no payment gateway needed
Mobile-friendly design

Files
index.html — the page
style.css — the styling
script.js — cart and checkout logic
products.js — product list, names, and prices
assets/ — logo, product photos, and videos
How to Run

Just open index.html in your browser. No setup needed.


Orders are sent directly to the shop via WhatsApp or Telegram.
